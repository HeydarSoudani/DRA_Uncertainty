---rules---
- Every member of the set the query computes over is one belief, "<member>: <property>". Name each member, the one kind of entity you may add, and list only members that fit the query's definition, not related entities (for example a predecessor, a broader group).
- Write the property with the query's qualifiers (for example a year, a unit) but no condition on its value.
- The last belief is what the query computes (for example a count, a sum, the earliest value), with every condition on the set and the values.

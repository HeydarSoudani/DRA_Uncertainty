You are a page mapper. Given a question, its answer, the facts it is built from and the pages it was written from, your task is to assign each fact the pages likely to state it. A fact is a statement about an entity, by its name or by a description; a blank (___) stands for a value the fact does not give.

== Rules ==
1. Assign a fact every page whose title makes it likely that the page states the fact: a page about the fact's entity, about its value, or about an event, work or list the fact belongs to. When in doubt, assign the page: a page assigned in vain costs little, a missed page loses the fact.
2. Decide from the titles only, without filling in any name or value; a fact no page fits gets no page.

== Output Format ==
Respond with ONLY a raw JSON object, no markdown, no code blocks, with one key:
- "facts": One object per fact, in fact order: {"fact": <fact number>, "pages": [<page numbers>]}.

Example question: Which painter, who taught Vincent van Gogh in The Hague, married a cousin of Van Gogh's mother?
Example answer: Anton Mauve
Example facts:
1. Anton Mauve taught Vincent van Gogh
2. Anton Mauve taught in The Hague
3. Anton Mauve married ___
4. the entity that Anton Mauve married was cousin of ___
5. an entity was mother of Vincent van Gogh
Example pages:
1. Wikipedia: Anton Mauve
2. Web: Anna Cornelia Carbentus - Van Gogh Museum
Example output:
{"facts": [
  {"fact": 1, "pages": [1]},
  {"fact": 2, "pages": [1]},
  {"fact": 3, "pages": [1]},
  {"fact": 4, "pages": [1, 2]},
  {"fact": 5, "pages": [2]}
]}

== Rules ==
The agent will write a short answer computed over every member of a set, for example a count, a sum, an average, or the earliest or latest value among the members.
1. The first criterion is the complete set of members, in the query's words, with the conditions that define the set. When the query counts or selects the members that meet a condition, that condition is not part of the set: it is the property.
2. Then list one criterion per member you are certain belongs to the set under the query's exact definition, as "<member>: <property>", where the property is what the query computes or counts. Leave out entities only related to the set (a similar role, a predecessor, a broader group) and members whose membership depends on how the definition is read.
3. The last criterion is "any other member: <property>", for the members you did not list. Write it even when you think your list is complete.

---example---
Example query: "How many novels by Jules Verne that were published before 1870 were adapted into films?"
Example output:
{
  "criteria": [
    "the complete list of the novels by Jules Verne that were published before 1870",
    "Five Weeks in a Balloon: adapted into a film",
    "Journey to the Center of the Earth: adapted into a film",
    "From the Earth to the Moon: adapted into a film",
    "The Adventures of Captain Hatteras: adapted into a film",
    "In Search of the Castaways: adapted into a film",
    "any other member: adapted into a film"
  ]
}

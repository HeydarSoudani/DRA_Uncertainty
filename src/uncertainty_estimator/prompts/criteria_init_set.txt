== Rules ==
The agent will write a short answer computed over every member of a set, for example a count, a sum, an average, or the earliest or latest value among the members.
1. The first criterion is the complete set of members, in the query's words, with the conditions that define the set, followed by the property of each member, where the property is what the query computes or counts. When the query counts or selects the members that meet a condition, that condition is not part of the set: it is the property.
2. Then list one criterion per member you are certain belongs to the set under the query's exact definition, as "<member>: <property>". Leave out entities only related to the set (a similar role, a predecessor, a broader group) and members whose membership depends on how the definition is read. These member criteria repeat the property of the first criterion for the members you know; this is the only overlap allowed.

---example---
Example query: "How many novels by Jules Verne that were published before 1870 were adapted into films?"
Example output:
{
  "criteria": [
    "the complete list of the novels by Jules Verne that were published before 1870, and for each whether it was adapted into a film",
    "Five Weeks in a Balloon: adapted into a film",
    "Journey to the Center of the Earth: adapted into a film",
    "From the Earth to the Moon: adapted into a film",
    "The Adventures of Captain Hatteras: adapted into a film",
    "In Search of the Castaways: adapted into a film"
  ]
}
